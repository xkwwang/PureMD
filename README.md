# PureMD — Markdown 预览（双击即看，默认只读、不主动修改源文件）

一个轻量的 Markdown 查看器：双击 `.md` 即渲染，**默认只读、不主动改动你的源文件，也不在磁盘上生成任何额外文件**（预览内容全部在内存里）。**只有在「编辑」模式里手动点「保存」才会写回，且只改你动过的段落。**

## 特性

- **默认只读、不主动改写**：默认双击打开就是只读预览，切换标签 / 关窗口都不会碰你的源文件，写论文 / 读文献时绝不担心被后台编辑软件改坏。只有点「✎ 编辑」进入编辑模式、再点「保存」才会写回。
- **标签栏下一行工具条**：最左的侧栏图标一键显示 / 隐藏左侧面板（`Ctrl+B` 同效，图标会跟着亮起）；面板打开时，图标右侧紧接着就是「文件 / 大纲 / 高亮」三个页签（面板收起时它们自动隐藏，不占地方）。右侧靠右排列「✎ 编辑」（「保存」紧随其后）、「高亮」（开启后选中文字立刻用当前颜色标注，旁边的色块可随时换色），再往右是「主题」与字号缩放组。
- **正文字号（只影响正文）**：工具条右侧有「A− / 百分比 / A+」和「适应窗口」。放大缩小只改变正文文字（连同代码块、表格一起等比缩放），**标签栏、工具条、侧栏等界面元素不会跟着变大**；`Ctrl+滚轮`、`Ctrl+=`、`Ctrl+-` 效果相同，点百分比或 `Ctrl+0` 回到 100%。「适应窗口」会让字号随窗口宽度自动调整——窗口拉宽字变大、收窄字变小，正文始终铺满可见区域；手动缩放一下即退出该模式。字号与模式都会被记住。
- **可编辑（点保存才写回）**：工具条上的「✎ 编辑」进入编辑模式即可直接改正文，改完点「保存」（`Ctrl+S`）才写回源文件；写前自动复制一份 `.bak`，并按原文件编码（UTF-8 / GBK）与原换行风格（CRLF / LF）写回。**只改你动过的段落，没碰过的内容逐字节不动**；有未保存修改时标签上会挂红点，切标签 / 关窗口 / 关标签前都会先问你。
- **三主题**：亮色 / 暗色 / 米色（护眼纸感），工具条右侧一键循环切换，关闭后记住你的选择（首帧即正确，不闪屏）。
- **本地图片直接显示**：md 里引用的本地图片（相对路径 / 绝对路径 / URL 编码空格均可，支持 png / jpg / gif / webp / svg / bmp / avif 等）会被只读地转成内嵌数据随预览一起渲染，**不再出现「图片裂图」**；远程图片照常直接加载。源文件零改动——保存回写时图片写的还是你原来的相对路径。
- **多标签 + 拖拽排序**：一行最多 6 个标签，多了出现左右箭头；标签可自由拖动排序；`☰` 按钮垂直列出全部标签（每项右侧都有 `×`，点它直接关掉对应标签，可连续关多个），列表里的项同样可以拖动调整顺序——**顶部标签栏会同步移动到相应位置**，两个入口看到的顺序永远一致；点空白处自动收起。关闭当前标签**之前**的标签时，后面的标签往前移补位、你仍停留在当前文档；关闭当前标签**之后**的标签时，自动选定到被关标签的前一个；关的就是当前标签时，选定到它的前一个。
- **无边框窗口自由缩放**：拖标题栏移动，拖四条边 / 四个角任意改大小；窗口处于最大化或贴靠屏幕边缘时，直接拖边缘会自动先还原成普通窗口再跟着鼠标缩放（不会出现「拖不动」）。
- **最大化不遮任务栏**：右上角 ▢ 最大化只铺满工作区，桌面任务栏始终露在外面；最大化后拖标题栏会先还原成原尺寸、摆到鼠标下方（抓取点按比例映射，光标仍留在标题栏上）再跟手，与原生 Windows 手感一致；按钮图标随状态在 ▢ / ⧉ 间切换。
- **历史恢复**：关闭时开着的标签会被记住，下次打开自动恢复上次的页面与激活项。
- **自动刷新**：开启后，源文件被外部编辑保存时自动重新渲染当前页。
- **可编辑高亮 + 备注**：选中正文文字即弹出八色调色板（黄 / 红 / 绿 / 蓝 / 紫 / 品红 / 橙 / 灰），点一下即可标注；点已有高亮可改颜色、写备注、删除；侧栏「高亮」页列出全文标注，点一条直接跳到正文对应位置（`Ctrl+Shift+H` 也可快速标注）。只读状态下标注只保存在本地配置里，**源 `.md` 一个字节都不会改**，保存编辑时也不会被写进文件；只有在编辑模式里加的标注（工具条「高亮」开着，或 `Ctrl+Shift+H`）才算文档内容，保存时写成 `==这段文字==`（黄色）或行内 `<mark style>`（其他颜色），在 Obsidian / Typora 等支持 `==` 的编辑器里同样能看到。
- **打开 / 重新加载 / 导出 PDF**：可一次打开多个文件；导出走系统打印对话框，选「另存为 PDF」即可存档。
- **文件树自动定位**：从任何地方打开 `.md`，左侧文件树会自动展开到它所在的目录、把当前文件高亮出来；如果它不在当前文件夹下，树根会自动切到它所属的文件夹，**不用每次手动「打开文件夹」**（切标签时也跟着定位）。标题行最左的「↑」可逐级**返回上一级文件夹**（再点再往上，直到磁盘顶层；换根后当前文档仍会自动展开并保持高亮，不会一换根就找不到它）。已经打开的文件，行尾还会出现一个 `×`，点它即可直接关掉对应标签（未打开的文件不显示）。
- **导出 Word（.docx）**：「导出」下拉里一键把当前文档转成可编辑的 .docx——标题/列表/表格/代码块/粗斜体/删除线/链接/图片全部保留，解析规则与预览完全一致（同一个 markdown 引擎）；字体统一为中文标题黑体、中文正文宋体、英文与数字 Times New Roman（代码保持等宽）。
- **GBK / 中文编码自动识别**：老文档常用 GBK/GB18030 也能正常显示，不乱码。
- **帮助菜单**：「帮助」下拉含 *检查更新*（联网查 GitHub Releases，有新版本弹窗显示版本号与更新说明，可一键打开发布页或跳过此版本）、*自动检查更新* 开关（默认开：每次启动约 2 秒后自动查一次，失败静默）、*反馈*（弹作者邮箱、一键复制，不自动打开邮件客户端）与 *关于*（显示版本号）。
- **完全离线、单文件分发**：打包后只有一个文件夹，发给朋友解压即用，无需安装、无需联网（检查更新除外）。

## 下载与安装

1. 到 [Releases](../../releases) 下载 `PureMD.zip`，解压到任意位置（如 `D:\Tools\PureMD`）。
   > 解压后**不要拆散 `PureMD` 文件夹**，它里面的 `_internal` 是运行依赖。
2. 双击 `关联 md 文件.cmd` → 看到「已设置成功」。
3. 之后双击任意 `.md` 即可预览；也可以直接把 `.md` 拖到 `PureMD.exe` 图标上打开（无需关联）。

### 系统依赖

需要 **Microsoft Edge WebView2 Runtime**。Win11 与较新的 Win10 已自带；若打开时提示「WebView2 启动失败」，请安装
[WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（免费）。

## 验证 Release 真伪（Sigstore 防伪）

每个 Release 附带三个文件：`PureMD.zip`（本体）、`PureMD.zip.sig`（签名）、`PureMD.zip.pem`（证书）。
下载后三者放同一目录，安装 [cosign](https://github.com/sigstore/cosign/releases) 后执行
（把 `v1.0.0` 换成你要验证的版本号）：

```bash
# Windows PowerShell / CMD 可去掉续行符 \ 写成一行
cosign verify-blob \
  --certificate PureMD.zip.pem \
  --certificate-identity "https://github.com/xkwwang/PureMD/.github/workflows/build.yml@refs/tags/v1.0.0" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  --signature PureMD.zip.sig \
  PureMD.zip
```

输出 `Verified OK` 即证明：该 zip 确实由本仓库的 GitHub Actions 构建产出，且发布后未被篡改。
（注意：`--certificate` 必须提供；只用 `--certificate-identity` 而不给证书文件，cosign 会报
"provide a key with --key or --sk, a certificate to verify against with --certificate ..." 错误。）

## 从源码构建

```bash
# 1) 准备 Python 环境（建议 3.10+，并用虚拟环境）
python -m venv venv && venv\Scripts\activate
pip install pyinstaller pywebview markdown-it-py[linkify] python-docx

# 2) 打包成单目录 exe（产物在 md_preview_app/PureMD/）
pyinstaller --noconsole --onedir --name PureMD ^
  --icon mdpreview/md_preview.ico ^
  --add-data "mdpreview;mdpreview" ^
  --collect-data webview --collect-submodules webview ^
  --collect-data docx --collect-submodules markdown_it --collect-submodules docx ^
  --hidden-import webview.platforms.edgechromium ^
  open_md_preview.pyw
```

也可以直接双击仓库里的 `rebuild_exe.cmd`（会跑上面的命令并做自检）。

## 配置

用户配置（主题、正文字号、是否默认开启自动刷新、上次关闭时的标签页会话）保存在：

```
%APPDATA%/PureMD/config.json
```

其中 `session.files` / `session.active` 记录上次关闭时打开的标签，下次启动时自动恢复；
删掉这两项（或整个配置文件）即可清空历史，不影响其它功能。

`highlights` 保存**只读状态下**的高亮与备注，按文件路径分桶；每条记录除了文字内容，还存了前后各 48 字的上下文与出现序号，
所以源文件小幅改动后仍能贴回原处。删除该键即清空全部高亮（源文件不受任何影响）。
> 编辑模式下做的标注属于文档本身，保存时直接写进 `.md`（`==文字==` / `<mark style>`），不再占用这个键。

## 正文字号

| 操作 | 效果 |
| --- | --- |
| `Ctrl+滚轮` / `Ctrl+=` / `Ctrl+-` | 放大 / 缩小正文文字（60%–300%，每档 10%）；界面元素尺寸不变 |
| 工具条「A−」「A+」 | 同上，点一下调一档 |
| 工具条百分比 | 点一下回到 100%（也可 `Ctrl+0`） |
| 「适应窗口」 | 字号随窗口宽度自动调整，让正文栏正好铺满可见区域；再点一次或手动缩放即退出 |

> 缩放只作用在正文（内容区），标签栏、工具条、侧栏、状态栏的字号始终固定——内核自带的整页缩放已被关闭，
> 所以不会再出现「一放大整个界面都变胖」的情况。

## 编辑与保存

| 操作 | 效果 |
| --- | --- |
| 点「✎ 编辑」/ 再点一次 | 进入 / 退出编辑模式（退出前会问要不要保存） |
| `Ctrl+S` 或「保存」 | 把改动写回源文件；同时把原文件复制成 `xxx.md.bak`（已有 `.bak` 时改用带时间戳的名字，绝不覆盖旧备份） |
| `Ctrl+Shift+H` | 给选中的文字加高亮；选区已在高亮里则取消 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（浏览器原生，同一编辑会话内有效） |
| `Esc` | 退出编辑模式 |

写回规则：只重写「被改过的块」，其余内容（包括空行、缩进、列表符号、代码块）逐字节沿用原文；
换行与编码沿用原文件（GBK 存回 GBK、CRLF 存回 CRLF），不会因为「另存」把整篇 diff 染红。

更新检查相关键：`auto_update_check`（`false` = 关闭启动时自动检查，仍可手动点「帮助 → 检查更新」）、
`skipped_version`（手动「跳过此版本」后记录，不再提醒该版本；删掉该项即可恢复提醒）。
检查更新访问 `api.github.com`，失败时静默跳过、不影响任何其它功能。
