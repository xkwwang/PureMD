PureMD · Markdown 纯预览便携版
================================

一个双击 .md 就能看渲染效果的小工具。默认只读打开、不主动改动你的 .md 源文件，
也不在你的电脑上生成任何额外文件（预览内容全部在内存里）。只有在「编辑」模式里手动点
「保存」才会写回，且只改你动过的段落。

有问题、建议或想反馈 Bug？欢迎发邮件到：xkwwang@126.com


【一、怎么装（一次性）】
--------------------------------
1) 把整个文件夹解压/复制到电脑上任意位置，比如 D:\Tools\PureMD。
   ⚠ 注意：文件夹里的 PureMD 目录不能拆开、不能只拷 .exe，
     它依赖旁边的 _internal 目录，必须整体在一起。

2) 双击「关联 md 文件.cmd」，看到「已设置成功」即可。
   （也可以直接双击 PureMD\PureMD.exe，程序会问你要不要关联。）
   这一步只写当前用户的注册表，不需要管理员权限，也不会动系统其它设置。

3) 之后双击任意 .md 文件，就会弹出预览窗口。


【二、怎么用】
--------------------------------
· 双击 .md               → 在预览窗口里新开一个标签页（已有窗口则复用）
· 把 .md 拖到 exe 图标上  → 同样可以打开，无需关联
· 顶部工具栏（从左到右）：
    「打开文件」  手动挑一个 .md
    「导出」      下拉菜单（与「帮助」同款 UI）：
                   · 导出 PDF  —— 走系统打印对话框，选“另存为 PDF”
                   · 导出 Word —— 保存为可编辑的 .docx：标题/列表/表格/代码块/
                                    粗斜体/删除线/链接/图片都保留，规则与预览一致；
                                    本地图片嵌进 docx，网络图片以“[图片]”占位。
                                    字体统一：中文标题黑体、中文正文宋体、
                                    英文与数字 Times New Roman（代码除外，保持等宽）。
    「重新加载」  重新渲染当前标签（比如别处改了文件）
    「自动刷新」  勾选后，文件被修改会自动重渲染（约 0.8 秒检测一次）
   「帮助」      下拉菜单：
                  · 检查更新 —— 联网查询 GitHub Releases 是否有新版本：
                                 有新版本会弹窗显示版本号与更新说明，可一键
                                 打开发布页下载，或「跳过此版本」不再提醒
                  · 自动检查更新 —— 开/关 开关（默认开）：
                                 开启后每次启动预览约 2 秒会自动检查一次，
                                 有新版本才弹窗；关闭后只在手动点「检查更新」时才查
                  · 反馈 —— 弹出作者邮箱，可一键复制，然后手动发邮件
                            （不会自动打开邮件客户端）
                  · 关于 —— 显示软件版本号与作者邮箱
· 标签栏：
    ‹ ›          左右滚动
    ☰            竖向列出所有标签，点名字直接跳转；
                  每项右侧有个「×」，点它直接关掉对应标签
                  （列表保持展开，可以连着关好几个）；
                  列表里的项也可以拖动调整顺序，顶部的
                  标签栏会同步移动到相应位置
    直接拖动标签  可以任意调整顺序（不会重新加载、不丢滚动位置，
                  与 ☰ 列表里拖动等价，两边顺序实时一致）
    关闭规则      关当前标签之前的标签：后面的往前移、你仍留在当前文档；
                  关当前标签之后的标签：自动选定到被关标签的前一个；
                  关的就是当前标签：选定到它的前一个。
· 一行最多显示 6 个标签，超出后用 ‹ › 滚动；窗口大小变化会自动重排。
· 窗口：拖标题栏可移动，拖四条边 / 四个角可任意改大小；右上角 ▢ 是最大化
  （窗口处于最大化或贴靠到屏幕边缘时，直接拖边缘会自动先还原成普通窗口，
  再跟着鼠标缩放，不会出现"拖不动"）。
· 工具条（标签栏下面一行，从左到右）：
    最左边        侧栏开关：一键显示 / 隐藏左侧面板，图标会跟着亮起；
                  快捷键 Ctrl+B 同效。面板打开时，图标右侧紧接着出现
                  「文件 / 大纲 / 高亮」三个页签；面板收起时它们自动隐藏。
    右侧一组（靠右排列，挨着主题）：
    「✎ 编辑」    进入 / 退出编辑模式（详见第三节），保存键紧挨在右边
    「高亮」      高亮工具：点亮后，选中正文文字会立刻用当前颜色标注，
                  不再弹调色板；再点一次关闭，恢复"选中弹气泡"
    色块 ▾        选颜色（八色）。选完会自动打开高亮工具
    「主题」      亮色 / 暗色 / 米色 三种循环切换（下次打开保持上次的主题）
    「A− A+」     缩小 / 放大正文文字，中间的百分比点一下回到 100%
    「适应窗口」  字号随窗口宽度自动调整：窗口拉宽字变大、收窄字变小，
                  正文始终铺满可见区域；再点一次（或手动缩放）即退出
· 字号：Ctrl+滚轮 / Ctrl+= / Ctrl+- 与按钮等效，范围 60%–300%，每档 10%；
  Ctrl+0 回到 100%。缩放只作用于正文（含代码块、表格），标签栏、工具条、
  侧栏等界面元素不会跟着变大；字号和「适应窗口」状态都会被记住。
· 图片：md 里引用的本地图片（相对路径、绝对路径、带空格用 %20 编码均可，
  支持 png / jpg / gif / webp / svg / bmp / avif 等常见格式）会直接显示，
  不再裂图；网络图片照常加载。预览只是把图片读进内存渲染，源文件零改动——
  以后在编辑模式里保存，图片写的还是你原来的相对路径。
  （单张超过 10MB 的图片不内联，以免内存暴涨，显示为上图前的原路径状态。）
· 历史恢复：关闭窗口时开着的所有标签会被记住，下次双击任意 .md 打开时
  自动恢复上次的标签页（并按上次的激活项定位）。新双击的文件会开在最前面。
· 左侧侧栏（点工具条最左的侧栏图标展开，拖动右边缘可调宽度；
  「大纲」「高亮」页没有标题行，正文列表直接从顶部开始）：
    「文件」  浏览一个文件夹里的所有 .md，点一下即开标签；
               打开任何 .md 时会自动展开到它所在的目录并把它标成蓝色，
               如果它不在当前文件夹下，文件树会自动切到它所属的文件夹，
               不用每次手动「打开文件夹」。
               已经打开的文件，行尾会出现一个「×」，点它即可直接关掉
               对应标签（未打开的文件不显示 ×）。
    「大纲」  列出当前文档的各级标题，点一条直达正文对应位置。
    「高亮」  列出本文所有标注，点一条跳到正文；标注可改色、写备注、删除。
· 高亮：选中正文里的文字会弹出八色调色板（黄/红/绿/蓝/紫/品红/橙/灰），
  点一下即完成标注；点已有高亮可改颜色、写备注或删除。
  只读状态下标注只保存在本机配置里，源 .md 文件一个字节都不会改。


【三、改文字（编辑模式）】
--------------------------------
· 点工具条上的「✎ 编辑」进入编辑模式，正文就可以直接改了（光标点进去打字、
  退格删除、Ctrl+Z 撤销都正常）。想退出再点一次，或用 Esc。
· 改完点「保存」或按 Ctrl+S，才会写回 .md 文件。不点保存，源文件永远不动。
· 第一次保存前会自动把原文件复制一份「原名.md.bak」放在同一目录，
  万一改坏了直接拿它覆盖回来即可。已有 .bak 时改用带时间戳的名字，不会覆盖旧备份。
· 只重写你改过的段落：没碰过的内容（含空行、缩进、列表符号、代码块）逐字节不动；
  文件原来的编码（UTF-8 / GBK）和换行风格（CRLF / LF）也会保持，不会整篇 diff 全红。
· 标签上出现红点时，表示这篇还有改动没保存；切标签、关标签、关窗口前都会先问你。
· 编辑模式下选中文字按 Ctrl+Shift+H 可以加高亮（再按一次取消）。此时高亮是文档的
  一部分，保存后会在源文件里写成 ==这段文字==（黄色）或行内 <mark style>（其它颜色），
  在 Obsidian / Typora 等支持 == 的编辑器里同样能看到。
  只读状态下做的标注和备注始终只存本机，保存编辑时也不会被写进文件。


【四、系统要求】
--------------------------------
· Windows 10 / 11
· 需要 Edge WebView2 Runtime（用来渲染界面）。
  Win11 和较新的 Win10 一般自带；若打开后提示「WebView2 启动失败」，
  去微软官网下载安装 "WebView2 Runtime" 即可（搜 Microsoft Edge WebView2）。


【五、常见问题】
--------------------------------
Q：双击 .md 没反应 / 打开了别的程序？
A：先关掉所有预览窗口，再重新运行一次「关联 md 文件.cmd」。
   若仍被其它程序（如 RStudio、Notepad++）占用，可在
   Windows 设置 → 应用 → 默认应用 → 按文件类型指定默认应用，把 .md 改成本程序。

Q：怎么查版本号？
A：点工具栏「帮助 → 关于」，第一行就是（如 PureMD v1.5.1）；
   也可以在命令行里运行  PureMD.exe --version  直接打印。

Q：文件图标没变成 M 图标？
A：重启一次「Windows 资源管理器」（任务管理器里重启 explorer.exe），或注销重登。

Q：想取消关联？
A：双击「取消关联.cmd」，之后 .md 恢复为系统默认行为，删掉本文件夹即可彻底清除。

Q：导出的 Word（.docx）能用什么打开？公式怎么办？
A：.docx 用 Word / WPS / LibreOffice 都能直接打开、继续编辑。
   注意：数学公式（$...$）在预览里就是纯文本显示，导出后同样是纯文本；
   需要正式公式排版，建议仍用 LaTeX / Overleaf，或导出 PDF 存档。

Q：检查更新查不到 / 提示网络不可达？
A：检查更新需要访问 api.github.com（GitHub 的接口）。打不开或特别慢时，
   自动检查会静默失败、不影响使用；可以晚点手动点「帮助 → 检查更新」再试，
   或先把「自动检查更新」关掉（关闭后随时还能手动检查）。
   检查更新只在点击后和启动后各查一次，不会后台反复联网。

Q：会不会偷偷改我的文件？
A：默认不会。程序以只读方式读取 .md，渲染结果只存在于内存；
   平时切换标签、关窗口都不碰你的源文件。只有在「编辑」模式下手动点
   「保存」才会写回，而且只改你动过的段落，没碰过的逐字节不动。


【六、卸载】
--------------------------------
双击「取消关联.cmd」，然后直接删除整个文件夹。不留任何残留。
